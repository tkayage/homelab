# Plan: 03 Compose Stack

## Must Haves

must_haves:

    - `docker-compose.yaml` runs Valkey with `1.5GB` limit, NATS with `2GB` limit, and Debezium with `1GB` limit.

## Threat Model

<threat_model>
- **T-05-06**: Runaway disk consumption by NATS JetStream. Mitigated by `max_file_store: 4Gb` limit in `nats.conf`.
- **T-05-07**: Unbounded memory usage by Valkey or NATS. Mitigated by Compose deploy limits (`1536M` and `2048M`).
- **T-05-08**: Cleartext secrets in git. Mitigated by using `.env.example` and injecting `.env` securely at runtime.
</threat_model>
