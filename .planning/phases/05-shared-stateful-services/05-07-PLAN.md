## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-07-01 | Tampering | NAS backup path | high | mitigate | Validate the subdirectory, canonicalize paths with `realpath`, require beneath-mount containment, and reject symlink component escapes. |
| T-05-07-02 | Tampering | Artifact validation-to-restore handoff | high | mitigate | Copy the selected artifact once into a private local snapshot, hash it, validate the snapshot, and restore the snapshot. |
| T-05-07-03 | Elevation of Privilege | Remote shell execution on services-01 | critical | mitigate | Strict-validate scratch name/image and pass values as quoted positional arguments to fixed remote scripts. |
| T-05-07-04 | Repudiation | Restore failure reporting | medium | mitigate | Preserve restore output on failure and record exact commands/evidence in `05-07-SUMMARY.md` and `05-VERIFICATION.md`. |
| T-05-07-05 | Integrity | Partial SQL restore | high | mitigate | Use SQL error-stop semantics and assert restored role plus database/global state before success. |
