<objective>
Port the proven gitops-platform.sh push flow to Go (`internal/gitops`) and add the SOPS encryption step
(`internal/gitops/sops.go`) so the scaffolder can render apps/<slug>/ into a gitops-homelab worktree,
encrypt the pull secret, and commit+push main — the initial GitOps registration that Argo's
ApplicationSet auto-adopts. Uses os/exec git + sops (NOT go-git) to reuse the repo's credential/askpass
convention verbatim.

Purpose: This is the scaffolder's one write into external state. It must reuse the exact askpass/token
pattern from gitops-platform.sh (x-access-token + GITHUB_TOKEN), preflight the push permission before
writing, and — the security-critical part — SOPS-encrypt the dockerconfigjson pull secret before commit
and refuse to push if a plaintext secret is present (threat T-06-06). The classic read:packages token
value that goes inside the secret is supplied by the operator (checkpoint in 06-08); this plan wires the
encryption mechanism and its guardrails.

Output: `internal/gitops` (git flow) + `internal/gitops/sops.go` (encryption + plaintext guard) with
integration tests against a LOCAL bare-repo fake origin (no network) and a real sops round-trip against a
throwaway age key.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator dev-box → gitops-homelab (initial commit push) | operator GITHUB_TOKEN crosses via x-access-token askpass; must not leak and must have push rights |
| plaintext filesystem → git (per-app secret) | the dockerconfigjson must be SOPS-encrypted before staging; plaintext must never be committed |
| age private key (dev-box) → sops encrypt | the operator age key at ~/.config/homelab/age/keys.txt is used for encryption only; never committed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-06 | Information Disclosure | plaintext dockerconfigjson in git | high | mitigate | EncryptPullSecret + assertNoPlaintextSecret run before git add; plaintext pull-secret.yaml removed; only .*\.enc\.yaml$ ciphertext is staged; matches .sops.yaml encrypted_regex ^(data|stringData)$ |
| T-06-16 | Spoofing / EoP | git push credential misuse | medium | mitigate | Reuse the x-access-token + GITHUB_TOKEN askpass flow; push preflight asserts the credential actually has push on gitops-homelab before writing (gitops-platform.sh lines 46-49) |
| T-06-17 | Information Disclosure | age key / token leakage via test artifacts | low | mitigate | Tests use throwaway age keys + dummy tokens in t.TempDir(); the real age key path is only referenced, never copied or logged |
</threat_model>
