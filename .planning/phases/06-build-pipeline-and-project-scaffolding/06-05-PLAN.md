<objective>
Author the five per-app GitOps manifest templates the scaffolder commits to
apps/<slug>/ in gitops-homelab, plus a `manifests.Render` that writes them, and prove the result
renders through `kustomize build`. This delivers SCAF-03 (gitops config from one slug) and SCAF-04
(health probes + private-GHCR pull credentials).

Purpose: Two verified facts make or break this deploy (RESEARCH Pitfalls 1 & 2): (1) SOPS filename
indirection — the on-disk secret is pull-secret.enc.yaml, but kustomization.yaml must reference the
DECRYPTED pull-secret.yaml, because the CMP decrypts `*.enc.yaml`→`*.yaml` and removes the ciphertext
before `kustomize build`; (2) the Deployment image string and the kustomization `images[].name` must be
byte-identical or the CI `kustomize edit set image` bump (06-04) no-ops and the pod runs :latest. Model
everything on the live edge-smoke + gitops-smoke exemplars.

Output: gitops/*.tmpl templates, manifests.Render, and a golden + kustomize-build test.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| plaintext filesystem → git (per-app secret) | the dockerconfigjson secret must be SOPS-encrypted before it can cross into gitops-homelab |
| kubelet → GHCR (private image pull) | the ghcr-pull dockerconfigjson (classic read:packages) authorizes the pull |
| gitops manifests → Argo CMP (kustomize build) | the CMP decrypts then runs stock kustomize build; filename indirection must be exact |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-06 | Information Disclosure | pull-secret.yaml plaintext | high | mitigate | This plan renders the plaintext shape only into t.TempDir() for the build test; no real token is written to a committed file; SOPS encryption + a refuse-to-commit-plaintext guard land in 06-06; .sops.yaml encrypted_regex ^(data|stringData)$ |
| T-06-14 | Tampering | SOPS filename indirection | high | mitigate | kustomization references the DECRYPTED pull-secret.yaml (Pitfall 1) — verified against live gitops-smoke + cmp-plugin.yaml — so kustomize build cannot fail closed on a missing file |
| T-06-15 | Tampering | image name / images[].name mismatch | medium | mitigate | Deployment image and images[].name kept byte-identical (Pitfall 2); asserted in the test so a bump can never silently no-op to :latest |
</threat_model>
