<objective>
Wave 0 groundwork: install the two missing dev-box tools (`sops`, `kustomize`) plus
`actionlint`, and bootstrap the isolated Go module for the scaffolder CLI with a cobra
skeleton that parses flags but does no work yet. This unblocks every later plan (nothing

and kustomizations cannot be validated. This plan also fixes the load-bearing assumptions
A1 (Go module path) and A2 (GHCR org `tkayage`) by documenting them and centralizing the
org in one place rather than silently baking them across the codebase.

Output: A runnable `scaffold` binary skeleton, `sops`/`kustomize`/`actionlint` on PATH, and
a README recording the two assumptions.
