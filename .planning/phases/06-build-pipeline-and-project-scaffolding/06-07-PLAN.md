<objective>
Wire every package built in waves 2–4 into one command and add the SCAF-05 completion report. The
orchestrator (`internal/scaffolder`) runs: preflight (git/sops/kustomize on PATH) → derive/validate slug →
detect T3/non-T3 + router → render the app-repo files (Dockerfile for T3 or validate existing for non-T3,
the deploy workflow, and the health route) → gitops.Publish (render+encrypt+commit apps/<slug>/) → report.
cobra's RunE replaces the 06-01 "not implemented" stub.

Purpose: SCAF-01 ("scaffold any containerizable project with one command") only becomes true when the
pieces are composed and proven end-to-end against a real temp repo. SCAF-05 ("reports created resources,
deployment status, and expected URL") is the operator's feedback: generated files, the gitops commit sha,
the expected URL https://<slug>.app.kayage.co, the Argo application name (<slug>), and how to check health.

Output: `internal/report`, `internal/scaffolder`, a wired main.go, and an end-to-end integration test that
scaffolds a T3 fixture and a non-T3 fixture against a local fake gitops origin.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator CLI args → app-repo + gitops writes | --slug/--port/--dockerfile drive file generation and a cross-repo commit |
| app repo (untrusted next.config / Dockerfile) → scaffolder | repo contents read for detection; T3 Dockerfile generated, non-T3 never overwritten |
| scaffolder → gitops-homelab (commit) | composes the 06-06 push flow; plaintext-secret guard must hold end-to-end |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-07 | Tampering | slug → app-repo/gitops paths | high | mitigate | slug.Validate runs before any write; --slug override validated identically; reject on failure (composed from 06-02) |
| T-06-06 | Information Disclosure | end-to-end plaintext secret | high | mitigate | Run composes gitops.Publish which encrypts + guards; the end-to-end test asserts only pull-secret.enc.yaml is committed |
| T-06-18 | Tampering | non-T3 Dockerfile overwrite | medium | mitigate | SCAF-06: non-T3 path validates only; the test asserts the fixture Dockerfile is byte-unchanged after Run |
</threat_model>
